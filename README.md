## Technologies used

Python · FastAPI · Streamlit · LangChain · LangGraph · Google ADK · MCP · A2A · Chroma · Hugging Face · scikit-learn · uv · Git · Docker configuration · GitHub Actions

Gemini is the configurable model default through `init_chat_model`. Provider/model, sampling parameters and retrieval counts are configurable. Public PDFs and datasets retain attribution.

## Engineering approach

Typed interfaces, tenant/user ownership, bounded operations, frozen dependencies, persisted state, failure tests and explicit validation limits. The standalone applications vendor a tested common runtime; they do not require another repository to run. Offline demos use clearly labeled model fixtures. Live-provider quality and deployment-specific checks remain explicit verification tasks.
