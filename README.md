# Hi, I'm Swaroop

I build Python applications and practical agentic AI projects, with a focus on clear APIs, evidence-grounded answers and reliable workflows.

## Featured project: AI Engineering Portfolio

[**InsightForge + six companion projects**](https://github.com/Swaroopfullstack/agentic-ai-portfolio)

- **InsightForge:** LangGraph supervisor with Data, RAG, ML, Tools and Memory specialists; Streamlit uploads, charts and session management.
- **EvidenceDesk:** LangChain + Chroma document Q&A, configurable Hugging Face embeddings, hybrid/MMR retrieval and page citations.
- **ReviewOps:** persisted human review with reviewer authorization, version checks and idempotent report exports.
- **ResearchSwarm:** parallel retrieval, evidence aggregation and bounded writer/critic review.
- **ProtocolBridge:** actual MCP tools/resources and A2A agent discovery/messages over attributed public data.
- **TripWise ADK:** stateful workflows, tools, callbacks and durable sessions.
- **Foundation Studio:** prompts, LCEL, structured results, streaming and tool-review middleware.

## Technologies I use in these projects

Python · FastAPI · Streamlit · LangChain · LangGraph · Google ADK · MCP · A2A · Chroma · Hugging Face · scikit-learn · uv · Git · Docker configuration · GitHub Actions

Gemini is the configurable model default through `init_chat_model`; provider/model and sampling/retrieval settings are centralized. Public PDFs and datasets include source attribution.

## Engineering approach

Typed interfaces, user-data ownership, bounded operations, reproducible dependencies, persistent state, failure tests and honest validation evidence. The portfolio includes 46 passing clean-environment tests plus a separately passing real embedding test. Live-model/cloud deployment checks and remaining external integrations are documented explicitly.
